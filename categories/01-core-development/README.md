# 01. Core Development

일반적인 구현 작업(백엔드, 프론트엔드, 모바일, API 설계)을 담당하는 핵심 에이전트 모음입니다.

포함된 에이전트:

- `api-designer` - REST/GraphQL API 계약 설계 및 검토
- `backend-developer` - 서버 로직, 데이터 계층, API 구현
- `code-mapper` - 코드 구조/의존성/소유 경계 파악
- `electron-pro` - Electron 앱 구조 및 데스크톱 통합
- `frontend-developer` - 웹 UI 구현 및 프론트엔드 개선
- `fullstack-developer` - 프론트엔드+백엔드 통합 구현
- `graphql-architect` - GraphQL 스키마/리졸버/페더레이션 설계
- `microservices-architect` - 서비스 분리, 인터페이스, 운영 전략
- `mobile-developer` - 모바일 앱 기능 구현 및 문제 해결
- `ui-designer` - UI 레이아웃/정보 구조/컴포넌트 설계
- `ui-fixer` - 재현 가능한 UI 결함의 최소 안전 수정
- `websocket-engineer` - 실시간 통신 및 이벤트 전달 구현
