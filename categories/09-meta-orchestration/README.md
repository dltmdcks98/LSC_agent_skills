# 09. Meta Orchestration

여러 하위 에이전트를 조합해 작업을 분배/조율하는 메타 에이전트 모음입니다.

포함된 에이전트:

- `agent-installer`
- `agent-organizer`
- `context-manager`
- `error-coordinator`
- `it-ops-orchestrator`
- `knowledge-synthesizer`
- `multi-agent-coordinator`
- `performance-monitor`
- `task-distributor`
- `workflow-orchestrator`

복잡한 멀티스텝 작업을 구조화하고 역할 충돌을 줄이는 데 도움이 됩니다.
