# Codex Subagent Category Reference

## 01-core-development

- `api-designer` (`categories/01-core-development/api-designer.toml`): 구현을 시작하기 전에 작업에 API 계약 설계, 개발 계획 또는 호환성 검토가 필요한 경우를 사용합니다.
- `backend-developer` (`categories/01-core-development/backend-developer.toml`): 실제 위치가 특정 장소에 지정된 백엔드 모양이 필요하거나 특수 버그 수정이 필요할 때 사용합니다.
- `code-mapper` (`categories/01-core-development/code-mapper.toml`): 변경된 재고 보관에 대한 보관 장소, 소유권 보관 및 보관에 대한 신뢰도가 높아질 때 사용할 수 있습니다.
- `electron-pro` (`categories/01-core-development/electron-pro.toml`): 전자 관련성이 필요하거나 메인/렌더러/사전 로드 경계, 패스키징 및 작업대를 사용하기 위해 사용자를 사용합니다.
- `frontend-developer` (`categories/01-core-development/frontend-developer.toml`): 범위에 대해 정밀한 구현이 필요하거나 변형의 변형 및 품질의 정도를 고려하여 UI 버그 수정이 필요한 경우에 사용하세요.
- `fullstack-developer` (`categories/01-core-development/fullstack-developer.toml`): 하나의 권한 기능이나 버그가 고급엔드와 백엔드에 있는 부분 및 단일 수입이 전체 경로를 소유해야 하는 경우에 사용합니다.
- `graphql-architect` (`categories/01-core-development/graphql-architect.toml`): 작업에 GraphQL을 사용하기 위해, 이해하기 위해 성능/보안 검토가 필요한 경우를 사용합니다.
- `microservices-architect` (`categories/01-core-development/microservices-architect.toml`): 작업에 대한 경계를 설계하고, 서비스를 제공하거나 시스템을 고려하고 있을 때 사용합니다.
- `mobile-developer` (`categories/01-core-development/mobile-developer.toml`): 앱 생활, API 통합, 기기/플랫폼 UX가 제공하는 별에 모바일 모양이 필요한 작업에 사용하세요.
- `ui-designer` (`categories/01-core-development/ui-designer.toml`): 작업에 개발 전이나 개발하는 UI 결정, 다양한 기능 디자인, 디자인을 포함하는 디자인 지침이 필요한 경우에 사용하세요.
- `ui-fixer` (`categories/01-core-development/ui-fixer.toml`): UI 문제가 이미 처리되고 상대방 에이전트가 가장 작은 보안 패치를 사용하려는 경우에 사용하세요.
- `websocket-engineer` (`categories/01-core-development/websocket-engineer.toml`): WebSocket 수명 유지, 메시지 계약 및 재연결/실패 동작에 사용되는 것은 전송 및 상태 작업을 사용할 때 사용됩니다.
